CÓMO USAR TU SITIO
==================

1. Para EDITAR tu sitio (agregar obras, cambiar información):
   → Ve a: www.joselothomassiny.com/admin.html
   → Ingresa tu contraseña
   → Haz los cambios que quieras
   → Haz clic en "Guardar" en cada sección

2. Para VER tu sitio:
   → Ve a: www.joselothomassiny.com

3. Para SUBIR FOTOS de tus obras:
   → Ve al panel → "Mis Obras"
   → Haz clic en "Editar" en la obra
   → Haz clic en la foto y selecciona tu imagen
   → Las fotos se guardan en la nube automáticamente

VENTAJAS DEL NUEVO SISTEMA
===========================
✓ Tus cambios aparecen en TODOS los dispositivos
✓ Las fotos no se pierden si cambias de computadora
✓ Puedes editar desde tu teléfono, tablet o cualquier computadora
✓ No hay límite de tamaño para tus fotos
